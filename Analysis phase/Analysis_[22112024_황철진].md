# 1.Introduction
### 1) Summary

현대 사회에서는 여러 종류의 약과 영양제를 동시에 복용하는 경우가 많지만, 복용 시간이나 방법을 정확히 기억하지 못하거나 신뢰할 수 있는 정보를 얻기 어려운 문제가 존재한다. 이러한 문제는 복용 누락, 오용, 그리고 약물 간 상호작용으로 인한 부작용을 초래할 수 있다.

본 시스템은 이러한 문제를 해결하기 위해 복약 일정 관리, 복용 기록 저장, 약/영양제 정보 제공, 그리고 사용자 리뷰 기능을 통합한 플랫폼을 제공한다. 사용자는 복용 시간을 설정하고 알림을 받을 수 있으며, 복용 여부를 기록하여 자신의 복약 이력을 체계적으로 관리할 수 있다. 또한 약/영양제에 대한 상세 정보와 다른 사용자의 리뷰를 통해 보다 신뢰성 있는 의사결정을 할 수 있도록 지원한다.

더불어 관리자 기능을 통해 사용자 계정, 리뷰, 약 정보를 관리할 수 있어 시스템의 신뢰성과 안정성을 유지할 수 있도록 설계되었다. 본 시스템은 사용자 중심의 직관적인 인터페이스를 제공함으로써 복약 순응도를 높이고, 보다 체계적인 건강 관리 환경을 제공하는 것을 목표로 한다.

### 2) Describe the features of project
첫째, 유용성 측면에서 본 시스템은 사용자의 복약 관리 부담을 줄여준다. 복용 일정 알림과 기록 기능을 통해 사용자는 복약 시간을 놓치지 않고 꾸준히 관리할 수 있으며, 이는 실제 건강 관리에 직접적인 도움을 준다.

둘째, 중요성 측면에서 본 시스템은 안전한 복약 환경을 제공한다. 약물 정보와 사용자 리뷰를 함께 제공함으로써 사용자는 보다 신뢰성 있는 정보를 바탕으로 약을 복용할 수 있으며, 이는 부작용 및 오용을 예방하는 데 기여한다.

셋째, 확장성 측면에서 본 시스템은 다양한 기능 확장이 가능하다. 예를 들어 병원 시스템과의 연동, 개인 건강 데이터 분석, AI 기반 복약 추천 시스템 등으로 발전할 수 있으며, 모바일 환경을 기반으로 다양한 플랫폼에서도 활용될 수 있다.

또한 관리자 기능을 통해 사용자 및 콘텐츠를 효율적으로 관리할 수 있어 시스템의 지속적인 운영과 품질 유지가 가능하다. 이러한 점에서 본 시스템은 단순한 정보 제공을 넘어 종합적인 건강 관리 플랫폼으로 확장될 가능성을 가진다.

# 3. Domain analysis
1) Control
Smart Medication & Supplement Management System에서 공통적으로 사용되는 제어 기능들을 포함하는 클래스이다.
ex) 화면 전환, 메시지 출력, 알림 표시, 입력 검증...

2) User
시스템을 사용하는 사용자들의 기본 정보를 가지는 클래스이다.
ex) 사용자 ID, 이메일, 비밀번호, 계정 상태...

3) Administrator
User를 상속받은 클래스로 시스템을 관리하는 관리자의 정보를 가지는 클래스이다.
ex) 관리자 권한, 관리 기능 접근 권한...

4) Medication
시스템에 등록된 약 정보를 가지는 클래스이다.
ex) 약 이름, 효능, 복용 방법, 주의사항...

5) Supplement
시스템에 등록된 영양제 정보를 가지는 클래스이다.
ex) 제품명, 효과, 섭취 방법, 주의사항...

6) Schedule
사용자가 등록한 복약 일정 정보를 가지는 클래스이다.
ex) 약 이름, 복용 시간, 복용 주기...

7) Notification
복약 일정에 따라 생성되는 알림 정보를 가지는 클래스이다.
ex) 알림 시간, 약 이름, 알림 상태...

8) IntakeRecord
사용자의 복용 기록 정보를 가지는 클래스이다.
ex) 약 이름, 복용 여부, 복용 시간...

9) Review
사용자가 작성한 약/영양제 리뷰 정보를 가지는 클래스이다.
ex) 작성자 ID, 약/영양제 ID, 별점, 리뷰 내용...

10) Login
사용자의 로그인 기능을 처리하는 클래스이다.
ex) 로그인 요청, 사용자 인증, 세션 생성...

11) Join
사용자의 회원가입 기능을 처리하는 클래스이다.
ex) 회원가입 요청, 입력값 검증, 사용자 정보 저장...

12) SearchMedication
약/영양제 검색 기능을 수행하는 클래스이다.
ex) 키워드 검색, 결과 목록 반환...

13) ViewMedicationInfo
약/영양제 상세 정보 조회 기능을 수행하는 클래스이다.
ex) 상세 정보 조회, 데이터 반환...

14) ManageSchedule
복약 일정 등록 및 관리 기능을 수행하는 클래스이다.
ex) 일정 등록, 일정 수정, 일정 삭제...

15) ManageIntakeRecord
복용 기록 입력 및 조회 기능을 수행하는 클래스이다.
ex) 기록 저장, 기록 조회...

16) ManageReview
사용자의 리뷰 작성, 수정, 삭제 기능을 수행하는 클래스이다.
ex) 리뷰 저장, 수정, 삭제...

17) ManageUser
관리자가 사용자 계정을 관리하는 기능을 수행하는 클래스이다.
ex) 사용자 조회, 계정 정지, 계정 삭제...

18) ManageReviewAdmin
관리자가 리뷰를 관리하는 기능을 수행하는 클래스이다.
ex) 리뷰 검토, 삭제, 숨김 처리...

19) ManageMedication
관리자가 약/영양제 정보를 관리하는 기능을 수행하는 클래스이다.
ex) 정보 추가, 수정, 삭제...

# 4. User Interface prototype
1. 시작 화면

###### <img src="./User Interface prototype img/1.시작 화면.jpg">

사용자가 시스템을 실행하면 시작 화면이 나타난다. 이 화면에서 사용자는 로그인, 회원가입, 비회원으로 시작 버튼을 선택할 수 있다. 로그인 버튼을 누르면 로그인 화면으로 이동하며, 회원가입 버튼을 누르면 회원가입 화면으로 이동한다. 비회원으로 시작할 경우 로그인 없이 복약 관련 기능을 사용할 수 있다.

2. 로그인 화면

###### <img src="./User Interface prototype img/2.로그인 화면.jpg">

시작 화면에서 로그인 버튼을 누르면 로그인 화면이 나타난다. 사용자는 이메일과 비밀번호를 입력한 후 로그인 버튼을 누른다. 입력한 정보가 올바르면 메인 화면으로 이동하며, 회원가입 버튼을 누르면 회원가입 화면으로 이동한다.

3. 회원가입 화면

###### <img src="./User Interface prototype img/3.회원가입 화면.jpg">

로그인 화면에서 회원가입 버튼을 누르면 회원가입 화면이 나타난다. 사용자는 이름, 이메일, 비밀번호를 입력한 후 회원가입 버튼을 누른다. 회원가입이 성공하면 로그인 화면으로 이동하며, 실패할 경우 오류 메시지가 출력된다.

4. 메인 화면

###### <img src="./User Interface prototype img/4.메인 화면.jpg">

로그인에 성공하면 메인 화면이 나타난다. 사용자는 약/영양제 검색, 복약 일정 등록, 복용 알림 확인, 복용 기록 조회, 사용자 정보 관리, 리뷰 관리 기능을 선택할 수 있다. 각 기능 버튼을 누르면 해당 기능 화면으로 이동한다.

5. 약/영양제 검색 화면

###### <img src="./User Interface prototype img/5.약과 영양제 검색 화면.jpg">

메인 화면에서 검색 기능을 선택하면 검색 화면이 나타난다. 사용자는 약 또는 영양제 이름을 입력한 후 검색 버튼을 누른다. 검색 결과 목록이 화면에 표시되며, 항목을 선택하면 상세 정보 화면으로 이동한다.

6. 약/영양제 정보 조회 화면

###### <img src="./6.약과 영양제 정보 조회 화면.jpg">

검색 결과에서 특정 항목을 선택하면 해당 약/영양제의 상세 정보가 표시된다. 사용자는 효능, 복용 방법, 주의사항을 확인할 수 있으며, 리뷰 보기 버튼을 통해 리뷰 화면으로 이동할 수 있다.

7. 리뷰 조회 화면

###### <img src="./User Interface prototype img/7.리뷰 조회 화면.jpg">

정보 조회 화면에서 리뷰 보기 버튼을 누르면 리뷰 화면이 나타난다. 사용자는 다른 사용자가 작성한 리뷰를 확인할 수 있으며, 리뷰 작성 버튼을 누르면 리뷰 작성 화면으로 이동한다.

8. 리뷰 작성 및 수정 화면

###### <img src="./User Interface prototype img/8.리뷰 작성 및 수정 화면.jpg">

사용자는 별점과 리뷰 내용을 입력한 후 저장 버튼을 눌러 리뷰를 등록하거나 수정할 수 있다. 저장이 완료되면 리뷰 조회 화면으로 돌아간다.

9. 복약 일정 등록 화면

###### <img src="./User Interface prototype img/9.복약 일정 등록 화면.jpg">

메인 화면에서 복약 일정 등록 기능을 선택하면 해당 화면이 나타난다. 사용자는 약 이름, 복용 시간, 복용 주기를 입력하고 등록 버튼을 누른다. 입력한 정보는 사용자 기기에 저장된다.

10. 복용 알림 확인 화면

###### <img src="./User Interface prototype img/10.복용 알림 확인 화면.jpg">

복약 시간이 되면 알림 화면이 나타난다. 사용자는 복용 완료 버튼을 눌러 복용 기록 입력 화면으로 이동하거나, 나중에 알림 버튼을 눌러 알림을 미룰 수 있다.

11. 복용 기록 입력 화면

###### <img src="./User Interface prototype img/11.복용 기록 입력 화면.jpg">

사용자는 복용 여부를 선택하여 기록을 저장할 수 있다. 저장이 완료되면 복용 기록 조회 화면으로 이동한다.

12. 복용 기록 조회 화면

###### <img src="./User Interface prototype img/12.복용 기록 조회 화면.jpg">

사용자는 이전에 저장한 복용 기록을 날짜별로 확인할 수 있다.

13. 사용자 정보 관리 화면

###### <img src="./User Interface prototype img/13.사용자 정보 관리 화면.jpg">

로그인한 사용자는 자신의 정보를 수정할 수 있으며, 로그아웃 기능을 사용할 수 있다.

14. 내 리뷰 관리 화면

###### <img src="./User Interface prototype img/14.내 리뷰 관리 화면.jpg">

사용자는 자신이 작성한 리뷰를 확인하고 수정하거나 삭제할 수 있다.

15. 관리자 메인 화면

###### <img src="./User Interface prototype img/15.관리자 메인 화면.jpg">

관리자는 사용자 관리, 리뷰 관리, 약/영양제 정보 관리 기능을 선택할 수 있다.

16. 사용자 관리 화면

관리자는 사용자 목록을 확인하고 계정 상태를 변경할 수 있다.

# 5. Glossary
| Term                    | Description                  |
| ----------------------- | ---------------------------- |
| Smart Medication System | 약과 영양제 복용을 관리하기 위한 시스템       |
| User                    | 시스템을 사용하는 일반 사용자             |
| Administrator           | 시스템을 관리하는 사용자                |
| Medication              | 사용자가 복용하는 의약품                |
| Supplement              | 건강 보조를 위한 영양제                |
| Review                  | 사용자가 약/영양제에 대해 작성한 평가 및 의견   |
| Schedule                | 사용자가 설정한 복약 일정               |
| Notification            | 복약 시간에 사용자에게 전달되는 알림         |
| Intake Record           | 사용자의 실제 복용 여부를 기록한 데이터       |
| Database                | 사용자 정보, 약 정보, 리뷰 등을 저장하는 저장소 |
| Login                   | 사용자가 계정으로 시스템에 접근하는 기능       |
| Logout                  | 사용자가 시스템에서 로그아웃하는 기능         |
| Search                  | 약/영양제를 검색하는 기능               |
| Profile                 | 사용자의 개인 정보 관리 기능             |
